# IB Circlio v1.0.2

IB Circlio is a privacy-first local Instagram follower and following history tracker.

## Included

- Automatic Followers and Following collection
- SQLite snapshots stored on the user's PC
- Detection of new and removed accounts between complete snapshots
- Stop support with partial snapshot saving
- Local report utility with timestamps and CSV output
- Password-protected database clearing
- Chrome, Edge, Brave, Opera, Vivaldi, and other Chromium browsers
- Firefox loading manifest
- Windows portable executables; Python is not required for end users

## Install

1. Download `IB-Circlio-1.0.2-windows.zip`.
2. Extract it to a normal folder.
3. Load the extracted folder as an unpacked extension.
4. Double-click `run_server.bat`.
5. Open an Instagram profile and click **Start collection**.

The local database is stored under `Desktop\Instagram Exporter Data`.
