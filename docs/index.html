Installation de l’extension

Choisissez votre navigateur

Suivez simplement les étapes correspondant au navigateur que vous utilisez déjà.

Browser extension setup

Choose your browser

Just follow the steps for the browser you already use.

Chrome, Edge, Brave, Opera, Vivaldi et autres navigateurs Chromium compatibles

  1. Ouvrez la page des extensions de votre navigateur, par exemple chrome://extensions, edge://extensions, brave://extensions, opera://extensions ou vivaldi://extensions.
  2. Activez le Mode développeur.
  3. Cliquez sur Charger l’extension non empaquetée (Load unpacked), puis sélectionnez le dossier extensions\chromium extrait du ZIP.

Chrome, Edge, Brave, Opera, Vivaldi, and other compatible Chromium browsers

  1. Open your browser’s extensions page, for example chrome://extensions, edge://extensions, brave://extensions, opera://extensions, or vivaldi://extensions.
  2. Turn on Developer mode.
  3. Click Load unpacked, then select the extracted extensions\chromium folder.

Firefox

  1. Ouvrez about:debugging, puis choisissez Ce Firefox.
  2. Cliquez sur Charger un module complémentaire temporaire….
  3. Dans le dossier extrait du ZIP, sélectionnez extensions\firefox\manifest.json.

Dans Firefox, cette extension temporaire doit être rechargée après la fermeture du navigateur.

Firefox

  1. Open about:debugging, then choose This Firefox.
  2. Click Load Temporary Add-on….
  3. In the extracted ZIP folder, select extensions\firefox\manifest.json.

In Firefox, reload this temporary extension after closing the browser.

Frequently asked questions

Dois-je installer Chrome ou Firefox ?

Non. Utilisez le navigateur que vous avez déjà. Le ZIP comprend l’extension pour Chrome, Edge, Brave et les autres navigateurs Chromium, ainsi que celle pour Firefox.

Où sont enregistrées mes données ?

Sur votre PC, dans la base de données locale d’IB Circlio. L’historique de vos collections n’est pas envoyé vers un compte cloud IB Circlio.

La collecte peut-elle manquer des comptes ?

La collecte dépend des éléments qu’Instagram affiche et charge dans le navigateur. Si la liste semble incomplète, IB Circlio marque le relevé comme partiel au lieu de le présenter comme une comparaison complète.

Pourquoi l’extension doit-elle être chargée dans le navigateur ?

Elle lit les listes affichées dans votre session Instagram, puis transmet le résultat au service qui tourne localement sur votre ordinateur.

Do I need to install Chrome or Firefox?

No. Use the browser you already have. The ZIP includes the extension for Chrome, Edge, Brave, and other Chromium browsers, as well as Firefox.

Where is my data stored?

On your PC, in IB Circlio’s local database. Your collection history is not sent to an IB Circlio cloud account.

Can the collection miss accounts?

Collection depends on what Instagram displays and loads in your browser. If a list appears incomplete, IB Circlio marks the snapshot as partial rather than presenting it as a complete comparison.

Why does the extension need to be loaded in my browser?

It reads the lists displayed in your Instagram session, then sends the results to the service running locally on your computer.
